# SIGEV - Front-end en React

Front-end del Sistema de Información para la Gestión de Ventas (SIGEV).
Evidencia GA7-220501096-AA4-EV03 - Faber Stiven Londoño Gil.

Módulos: Productos, Clientes y Ventas.

## Cómo ejecutarlo

```
npm install
npm run dev
```

Se abre en http://localhost:5173

## Datos

Por ahora usa datos de prueba guardados en el navegador (localStorage).
Cuando estén las API REST de SIGEV (AA5), se cambia `USAR_API = true`
en `src/services/api.js`.
